# 🎯 Quiz App

A simple and interactive quiz application built with **HTML**, **CSS**, and **JavaScript**. This app provides users with a fun way to test their knowledge across different topics.


---

## 🚀 Live Demo

🔗 [Click here to try the quiz!](https://MohamedFathy9.github.io/Quiz-app)

---

## 🛠 Features

- 🧠 Multiple choice questions
- ✅ Instant answer feedback (correct/wrong)
- ⏱ Countdown timer per question
- 📊 Final score with progress circle
- ✨ Smooth animations and UI transitions
- 🎨 Responsive and modern UI design
